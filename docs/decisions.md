# Décisions prises sans validation

Chaque décision indique la date, le sujet, le choix, la raison et la façon de revenir dessus.
Les décisions structurantes renvoient à un ADR (`docs/adr/`).

| D-001 | 2026-10-31 | Cahier des charges absent | `docs/cahier-des-charges.md` n'est pas dans le dépôt. Le référentiel d'exigences est **reconstitué** dans `docs/recette/exigences.csv` à partir des skills et de `CLAUDE.md` ; chaque ligne indique sa source (« skill … » ou « reconstitué »). Les identifiants « reconstitués » et les critères de sortie du §9.2 sont provisoires. | Les skills citent la plupart des identifiants (RG-01 à RG-14, PLA, TAR, CAU, DOC, SIG, MOB, PER, VAL, IMP, DSH…) ; les familles REF, USR, COM, MAT, STA sont complétées par l'option la plus raisonnable. | Déposer le cahier des charges, puis corriger `exigences.csv` (libellés, priorités, lots) : la matrice `docs/recette/matrice.csv` se régénère par `make matrice` et signale toute exigence sans test. |
| D-002 | 2026-10-31 | Dépôt Git | `git init` local sur `main`, aucun dépôt distant. | Le dossier n'était pas un dépôt ; les commits locaux sont demandés. | Ajouter le dépôt distant de la Ville (`git remote add`). |
